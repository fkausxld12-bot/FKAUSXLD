# 🌸 꽃 작업장 주문 관리

작업장 컴퓨터에서 실행해 두면 **농라F(farmer4989.com) 주문서가 자동으로 주문 목록에 들어오는** 프로그램입니다.
설치는 아래 **원클릭 설치**로 끝나고, 같은 와이파이의 휴대폰에서도 같은 화면을 볼 수 있습니다.

## 원클릭 설치 · 업데이트 (작업장 컴퓨터)

1. **[⬇ 설치 파일 받기](https://github.com/fkausxld12-bot/FKAUSXLD/archive/refs/heads/main.zip)** 를 누르면
   `FKAUSXLD-main.zip` 이 받아집니다.
2. 받은 파일을 열고, 안에 있는 **`설치하기`** 를 두 번 누릅니다.
   (경고 창이 뜨면 **[실행]**, 파란 창이면 **[추가 정보] → [실행]**)
3. 끝입니다. Node.js가 없으면 알아서 설치하고(처음 한 번, [예] 한 번 누르기),
   최신 프로그램을 받아 바탕화면에 **[꽃 작업장 주문]** · **[꽃 작업장 업데이트]** 아이콘을 만든 뒤 프로그램을 켭니다.

다음부터는 **[꽃 작업장 주문]** 으로 켜고, 새 버전이 나오면 **[꽃 작업장 업데이트]** 를 두 번 누르면 됩니다.
주문·설정 기록은 따로 보관되어 업데이트해도 그대로 남습니다.

## 어떻게 돌아가나

1. **농라F 주문서 자동 연동** — 3분마다 주문서 게시판을 확인해서, 새 주문서가 올라오면
   품목·수량·받는분·연락처·주소를 읽어 **자동으로 주문 목록에 등록**합니다. 버튼 누를 필요 없습니다.
   새 주문이 들어오면 알림음이 울리고 화면에 표시됩니다.
2. **현장 판매도 농라F로** — 현장에서 판매하면 농라F에 주문서를 넣으세요.
   프로그램이 자동으로 가져와서 수량에 합산됩니다. 따로 입력할 것이 없습니다.
3. **품목별 주문 수량 자동 집계** — 주문이 들어올 때마다 품목별 오늘/전체 수량이 자동으로 맞춰집니다.
4. **경매 낙찰서로 매입 기록** — 공판장에서 **거래내역(낙찰서) 엑셀**을 받기만 하면
   다운로드 폴더에서 **몇 초 안에 저절로 들어옵니다.** (이름에 '낙찰'이 들어간 엑셀만 보며, 끌 수 있습니다)
   직접 올릴 때는 [📥 낙찰서 엑셀 올리기]를 누르거나 파일을 화면에 **끌어다 놓으면** 되고, 여러 개도 한 번에 됩니다.
   날짜별 매출과 맨 위 **이번 장** 칸에 **남는 돈(매출−매입)** 이 나오고, **이번 달·지난 달 합계**도 보입니다.
   **[📊 장부 엑셀]** 을 누르면 날짜별 매출·매입·남는 돈과 달마다 합계를 엑셀로 받을 수 있습니다.
5. **스마트스토어 자동 연동** — 커머스API센터에서 발급받은 애플리케이션 ID/시크릿을
   설정에 저장하면 **결제된 주문이 5분마다 자동으로** 들어옵니다. (배송비 제외 금액으로 기록)
   설정 방법: ① commerce-api.naver.com 에서 애플리케이션 등록 (API호출 IP에는 작업장 컴퓨터의
   공인 IP — 네이버에 "내 IP" 검색 — 를 입력) ② 발급된 ID/시크릿을 프로그램의
   "스마트스토어 자동 연동 → 설정"에 붙여넣기. 키는 작업장 컴퓨터에만 저장됩니다.
6. 주문마다 **완료/취소** 처리를 할 수 있고, 어느 기기에서 봐도 3초 안에 같은 내용으로 동기화됩니다.
   주문 목록의 **🔍 찾기** 칸에 이름·전화번호 일부·품목을 넣으면 완료된 주문까지 전부에서 바로 찾습니다.

## 직접 설치하는 법 (원클릭 설치를 쓰지 않을 때)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (한 번만)
2. 이 폴더의 **`시작하기.bat`** 을 더블클릭합니다.
   - 검은 창이 뜨면서 브라우저가 자동으로 열립니다.
   - 검은 창을 닫으면 프로그램이 꺼집니다. 켜 둔 채로 쓰세요.
3. Mac/리눅스라면 터미널에서 `node server.js` 로 실행합니다.

## 농라F 연동 (한 번만)

1. 농라F에서 **주문서 게시판**(주문서 아무거나 연 상태)의 주소를 복사합니다.
   (예: `https://farmer4989.com/gnuboard5/bbs/board.php?bo_table=ymh14141&wr_id=49`)
2. 프로그램에서 **설정** 버튼 → 주소 붙여넣기 → **저장하고 연동 시작**
3. **비밀글 주문서**까지 자동 등록하려면 농라 아이디/비밀번호도 저장하세요.
   (작업장 컴퓨터의 `data/db.json`에만 저장되고 밖으로 나가지 않습니다)

## 휴대폰에서 보기

작업장 컴퓨터와 **같은 와이파이**에 연결한 뒤,
실행 창에 나오는 `http://192.168.x.x:4000` 주소를 휴대폰 브라우저에 입력하세요.

## 송장 도우미 (롯데택배)

1. 프로그램에서 **[송장 창 열기]** → 롯데 파트너 창이 열립니다.
2. 그 창에서 **직접 로그인**하고 **건별주문접수** 화면을 띄워 둡니다.
   (비밀번호는 프로그램이 절대 입력하지 않습니다)
3. 주문 목록에서 **[송장]** 버튼 → 수하인·주소·수량·상품명이 자동으로 채워집니다.
4. 채운 내용을 확인 창에서 보고 **확인**을 누르면 저장되고, 그 주문은 발송 완료로 바뀝니다.

> 송하인·거래처·집하점은 읽기만 하고 절대 건드리지 않습니다.
> 송하인이 비어 있으면 중단합니다. 같은 주문을 두 번 등록하려 하면 경고합니다.

### 창이 안 열릴 때

- **[강제 다시 열기]** — 멈춰 있는 송장 창을 닫고 새로 엽니다. 대부분 이걸로 해결됩니다.
- 크롬이 없으면 **엣지·웨일**도 자동으로 찾습니다. 그래도 못 찾으면
  크롬 실행 파일 경로(`chrome.exe`)를 물어보고, 넣어 주면 그 경로를 기억합니다.
- 프로그램이 연 **새 창에서만** 로그인해야 합니다. 평소 쓰시던 브라우저 창은
  프로그램이 들여다볼 수 없습니다.

## 뭐가 문제인지 프로그램이 직접 알려줍니다

화면 맨 아래 **[🩺 전체 점검]** 을 누르면 농라F 로그인·상품 동기화·주문 수집·
스토어 연동·송장 브라우저·송장 화면 인식 상태를 한 번에 확인해서,
**문제가 있으면 무엇을 어떻게 고쳐야 하는지 한국어로** 알려줍니다.

## 프로그램이 잘 도는지 스스로 확인하기

**`자체점검.bat`** 을 더블클릭하면 모의 사이트로 전체 기능(농라F 연동·주문 수집·
현장 판매·문자 주문·날짜별 매출·송장 도우미·재시작 후 데이터 유지)을 자동으로
점검하고 결과를 알려줍니다.

## 데이터 — 업데이트해도 유지됩니다

모든 내용(주문 기록, 농라F·스토어 연동 키)은 프로그램 폴더가 아니라
**사용자 홈 폴더의 `.flower-workshop\db.json`** 에 저장됩니다.
그래서 **프로그램을 새로 내려받아도 설정을 다시 넣을 필요가 없습니다.**
연동 키는 한 번만 넣으면 계속 유지되고, 이 파일 하나만 복사해 두면 백업이 됩니다.
(예전 버전을 쓰던 경우 첫 실행 때 기존 데이터를 자동으로 옮겨옵니다)
