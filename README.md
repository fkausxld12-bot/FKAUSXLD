# 🌸 꽃 작업장 주문·판매 관리

작업장 컴퓨터에서 실행해 두고 쓰는 주문/재고/판매 프로그램입니다.
설치할 것은 Node.js 하나뿐이고, 같은 와이파이에 있는 휴대폰에서도 접속됩니다.

## 할 수 있는 것

| 탭 | 기능 |
|---|---|
| **주문 확인** | 농라/스토어 주문을 등록하면 채널별 신규 주문 건수가 한눈에 보입니다. 신규 → 입금확인 → 발송대기 → 발송완료 순서로 처리하고, 주문이 잡히면 재고가 자동으로 빠집니다. 취소하면 재고가 복구됩니다. |
| **현장 판매** | 품목 버튼을 눌러 담으면 합계가 계산되고, 받은 돈을 넣으면 거스름돈까지 나옵니다. "판매 완료"를 누르면 재고가 자동으로 빠집니다. |
| **재고** | 주문 목록 텍스트를 그대로 붙여넣어 품목을 등록합니다. 예: `장미)자나(sp)(10개) 60,000원` → 재고 10개, 개당 6,000원. +/− 버튼으로 수량을 직접 조정할 수도 있습니다. |
| **송장 출력** | 발송 안 된 주문을 체크해서 **한 번에** 송장(주소 라벨)을 A4로 인쇄합니다. 출력하면 자동으로 발송완료 처리됩니다. |

## 시작하는 법 (작업장 컴퓨터)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (한 번만)
2. 이 폴더의 **`시작하기.bat`** 을 더블클릭합니다.
   - 검은 창이 뜨면서 브라우저가 자동으로 열립니다.
   - 검은 창을 닫으면 프로그램이 꺼집니다. 켜 둔 채로 쓰세요.
3. Mac/리눅스라면 터미널에서 `node server.js` 로 실행합니다.

## 휴대폰에서 보기 (현장에서 수량 빼기)

작업장 컴퓨터와 **같은 와이파이**에 연결한 뒤,
실행 창에 나오는 `http://192.168.x.x:4000` 주소를 휴대폰 브라우저에 입력하세요.
어느 기기에서 수량을 빼도 3초 안에 모든 화면이 같이 바뀝니다.

## 데이터

모든 내용은 `data/db.json` 파일에 저장됩니다.
컴퓨터를 껐다 켜도 그대로 남고, 이 파일만 복사해 두면 백업이 됩니다.

## 아직 안 되는 것

- **농라(밴드)·스마트스토어 주문 자동 가져오기**: 네이버 커머스 API 키(스마트스토어 판매자센터에서 발급)와 밴드 API 승인이 있어야 가능합니다. 키가 준비되면 연동을 붙일 수 있는 구조로 만들어 두었습니다. 지금은 주문 내용을 복사해 붙여넣으면 자동으로 품목/수량/금액을 읽어 등록합니다.
- **택배사 공식 송장**: 인쇄되는 것은 주소 라벨(받는 분/연락처/주소/품목)입니다. 택배사 시스템(굿스플로 등) 연동 송장은 택배사 계약 정보가 필요합니다.
