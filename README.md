# 🌸 꽃 작업장 주문·판매 관리

작업장 컴퓨터에서 실행해 두고 쓰는 주문/재고/판매 프로그램입니다.
설치할 것은 Node.js 하나뿐이고, 같은 와이파이에 있는 휴대폰에서도 접속됩니다.

## 할 수 있는 것

| 탭 | 기능 |
|---|---|
| **주문** | 농라/스토어 주문을 채널별로 관리합니다. 신규 → 입금확인 → 발송대기 → 발송완료 순서로 처리하고, 주문이 잡히면 재고가 자동으로 빠집니다. 취소하면 재고가 복구됩니다. 각 주문에 **송장 출력 여부**가 표시되고, "송장 안 뽑은 주문"만 골라 볼 수도 있습니다. |
| **농라** | 농라(farmer4989.com) 판매글의 댓글을 3분마다 자동으로 가져옵니다. 새 판매글을 올려도 자동으로 최신 글을 따라가고, 새 댓글이 오면 알림음이 울립니다. 댓글에서 **주문 등록**을 누르면 내용이 주문 폼에 자동으로 채워지고, 등록하면 재고가 빠집니다. 처리한 댓글은 표시되어 두 번 등록되지 않습니다. |
| **현장 판매** | 품목 버튼을 눌러 담으면 합계가 계산되고, 받은 돈을 넣으면 거스름돈까지 나옵니다. "판매 완료"를 누르면 재고가 자동으로 빠집니다. |
| **재고** | 주문 목록 텍스트를 그대로 붙여넣어 품목을 등록합니다. 예: `장미)자나(sp)(10개) 60,000원` → 재고 10개, 개당 6,000원. +/− 버튼으로 수량을 직접 조정할 수도 있습니다. |
| **송장** | 발송 안 된 주문을 체크해서 **한 번에** 송장(주소 라벨)을 A4로 인쇄합니다. 출력한 주문에는 "송장 ✓" 표시가 남고, 안 뽑은 주문만 기본으로 체크됩니다. |

## 농라(farmer4989.com) 연동하는 법

1. 농라 사이트에서 **내 판매글**을 열고 주소창의 주소를 복사합니다.
   (예: `https://farmer4989.com/gnuboard5/bbs/board.php?bo_table=ymh14141&wr_id=49`)
2. 프로그램의 **농라 탭 → 설정 열기**에 주소를 붙여넣고 **저장하고 연동 시작**을 누릅니다.
3. **비밀댓글**까지 보려면 농라 사이트 아이디/비밀번호도 함께 저장하세요.
   (작업장 컴퓨터의 `data/db.json`에만 저장되고 밖으로 나가지 않습니다)
4. 연동 후에는 **3분마다 자동으로** 새 댓글을 확인합니다. 새 댓글이 오면
   알림음이 울리고 농라 탭 배지에 개수가 표시됩니다.
   "항상 최신 글 따라가기"가 켜져 있으면 새 판매글을 올려도 자동으로 그 글을 봅니다.
   급할 때는 **지금 바로 확인** 버튼으로 즉시 가져올 수 있습니다.

## 시작하는 법 (작업장 컴퓨터)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (한 번만)
2. 이 폴더의 **`시작하기.bat`** 을 더블클릭합니다.
   - 검은 창이 뜨면서 브라우저가 자동으로 열립니다.
   - 검은 창을 닫으면 프로그램이 꺼집니다. 켜 둔 채로 쓰세요.
3. Mac/리눅스라면 터미널에서 `node server.js` 로 실행합니다.

## 휴대폰에서 보기 (현장에서 수량 빼기)

작업장 컴퓨터와 **같은 와이파이**에 연결한 뒤,
실행 창에 나오는 `http://192.168.x.x:4000` 주소를 휴대폰 브라우저에 입력하세요.
어느 기기에서 수량을 빼도 3초 안에 모든 화면이 같이 바뀝니다.

## 데이터

모든 내용은 `data/db.json` 파일에 저장됩니다.
컴퓨터를 껐다 켜도 그대로 남고, 이 파일만 복사해 두면 백업이 됩니다.

## 아직 안 되는 것

- **스마트스토어 주문 자동 가져오기**: 네이버 커머스 API는 판매자센터에서 애플리케이션 등록·승인이 필요합니다. 승인되면 연동을 붙일 수 있는 구조입니다. 지금은 주문 내용을 복사해 붙여넣으면 자동으로 품목/수량/금액을 읽어 등록합니다.
- **택배사 공식 송장**: 인쇄되는 것은 주소 라벨(받는 분/연락처/주소/품목)입니다. 택배사 시스템(굿스플로 등) 연동 송장은 택배사 계약 정보가 필요합니다.
