# 🌸 꽃 작업장 주문 관리

작업장 컴퓨터에서 실행해 두면 **농라F(farmer4989.com) 주문서가 자동으로 주문 목록에 들어오는** 프로그램입니다.
설치할 것은 Node.js 하나뿐이고, 같은 와이파이의 휴대폰에서도 같은 화면을 볼 수 있습니다.

## 어떻게 돌아가나

1. **농라F 주문서 자동 연동** — 3분마다 주문서 게시판을 확인해서, 새 주문서가 올라오면
   품목·수량·받는분·연락처·주소를 읽어 **자동으로 주문 목록에 등록**합니다. 버튼 누를 필요 없습니다.
   새 주문이 들어오면 알림음이 울리고 화면에 표시됩니다.
2. **현장 판매도 농라F로** — 현장에서 판매하면 농라F에 주문서를 넣으세요.
   프로그램이 자동으로 가져와서 수량에 합산됩니다. 따로 입력할 것이 없습니다.
3. **품목별 주문 수량 자동 집계** — 주문이 들어올 때마다 품목별 오늘/전체 수량이 자동으로 맞춰집니다.
4. **스마트스토어 자동 연동** — 커머스API센터에서 발급받은 애플리케이션 ID/시크릿을
   설정에 저장하면 **결제된 주문이 5분마다 자동으로** 들어옵니다. (배송비 제외 금액으로 기록)
   설정 방법: ① commerce-api.naver.com 에서 애플리케이션 등록 (API호출 IP에는 작업장 컴퓨터의
   공인 IP — 네이버에 "내 IP" 검색 — 를 입력) ② 발급된 ID/시크릿을 프로그램의
   "스마트스토어 자동 연동 → 설정"에 붙여넣기. 키는 작업장 컴퓨터에만 저장됩니다.
5. 주문마다 **완료/취소** 처리를 할 수 있고, 어느 기기에서 봐도 3초 안에 같은 내용으로 동기화됩니다.

## 시작하는 법 (작업장 컴퓨터)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (한 번만)
2. 이 폴더의 **`시작하기.bat`** 을 더블클릭합니다.
   - 검은 창이 뜨면서 브라우저가 자동으로 열립니다.
   - 검은 창을 닫으면 프로그램이 꺼집니다. 켜 둔 채로 쓰세요.
3. Mac/리눅스라면 터미널에서 `node server.js` 로 실행합니다.

## 농라F 연동 (한 번만)

1. 농라F에서 **주문서 게시판**(주문서 아무거나 연 상태)의 주소를 복사합니다.
   (예: `https://farmer4989.com/gnuboard5/bbs/board.php?bo_table=ymh14141&wr_id=49`)
2. 프로그램에서 **설정** 버튼 → 주소 붙여넣기 → **저장하고 연동 시작**
3. **비밀글 주문서**까지 자동 등록하려면 농라 아이디/비밀번호도 저장하세요.
   (작업장 컴퓨터의 `data/db.json`에만 저장되고 밖으로 나가지 않습니다)

## 휴대폰에서 보기

작업장 컴퓨터와 **같은 와이파이**에 연결한 뒤,
실행 창에 나오는 `http://192.168.x.x:4000` 주소를 휴대폰 브라우저에 입력하세요.

## 데이터

모든 내용은 `data/db.json` 파일에 저장됩니다.
컴퓨터를 껐다 켜도 그대로 남고, 이 파일만 복사해 두면 백업이 됩니다.
