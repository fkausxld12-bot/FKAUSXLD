# 현풍 농장 CCTV — 농가는 버튼 한 번

CCTV로 가는 길을 두 개 만들었습니다. **둘 다 농가가 주소·포트·비밀번호를 치지 않습니다.**

| | ① 앱 없이 보기 (권장) | ② 기존 앱(EasyViewer Pro)으로 보기 |
|---|---|---|
| 농가가 하는 일 | 버튼 한 번 | 처음 한 번만 [복사]→[붙여넣기] 5번, 다음부터는 앱만 열기 |
| 앱 설치 | 필요 없음 | 필요 |
| 검은 화면 | H.264로 바꿔 내보내서 안 생김 | 앱이 알아서 함 |
| 관비기 컴퓨터 | 켜져 있어야 함 | 꺼져 있어도 됨 |

두 길을 같이 두는 이유가 있습니다. ①은 제일 쉽지만 관비기 컴퓨터가 꺼지면 안 됩니다.
②는 컴퓨터와 상관없이 되지만 처음 등록이 필요합니다. 사이트에는 둘 다 버튼으로 넣어 두었습니다.

| 파일 | 무엇 |
|---|---|
| `go2rtc.yaml` | ① 의 설정 — 관비기 컴퓨터에 둡니다 |
| `CCTV_켜기.bat` | ① 을 켜는 파일 |
| `cctv-web/` | ① 에서 농가가 보는 화면 (`video-rtc.js`·`video-stream.js` 는 go2rtc 1.9.14 의 재생기, MIT) |
| `앱-설정-도우미.html` | ② 를 위한 화면 — 사이트에 올립니다 |
| `사이트-버튼.html` | 사이트 CCTV 칸에 붙여 넣을 덩어리 |

---

## 왜 지금까지 막혔나

**1. 웹 CCTV 플레이어가 검은 화면이었던 이유 — 앱이나 글꼴 문제가 아니라 코덱입니다.**

현풍 NVR 영상은 **HEVC(H.265)** 입니다. 브라우저는 이 영상을 웹페이지 안에서 직접 풀지 못합니다.
그래서 소리도 그림도 없는 검은 네모만 나옵니다.

이번에 같은 상황(H.265 704×480)을 만들어 재현해 봤고, 브라우저가 뱉은 말이 이것입니다.

```
mse: streams: codecs not matched: video:H265 …
webrtc/offer: streams: codecs not matched: video:H265 …
```

**중간에서 H.264로 바꿔 주면 그냥 나옵니다.** `go2rtc.yaml` 의 두 번째 줄들이 그 일을 합니다.
바꿔서 나온 영상을 확인해 봤습니다 — `Video: h264 (High) 704x480`. 검은 화면이 안 나는 이유입니다.

**2. EasyViewer Pro에 장치를 자동 등록시키는 방법은 없습니다.**

EasyViewer Pro와 그 형제 앱(DMSS 등)에는 **밖에서 주소·포트·계정을 넣어 주는 공식 딥링크가 없습니다.**
공식 자동 등록 통로는 **QR(장치 카드)** 하나뿐인데, 그건 본인 휴대폰 화면을 본인이 찍어야 해서
쓰기 어렵다고 하셨던 그 방식입니다.

그래서 '자동 등록'은 포기하고, **한 글자도 안 치게** 만들었습니다 → `앱-설정-도우미.html`

## ① 앱 없이 보기 (권장)

```
NVR (eemi124.iptime.org:554, H.265)
        │  RTSP
        ▼
관비기 컴퓨터 : go2rtc  ──► H.264로 변환 ──► 농가 휴대폰 크롬
        │
        └─ 화면도 같이 내보냄  http://eemi124.iptime.org:1984/
```

사이트의 **[📹 현풍 CCTV 보기]** 는 저 주소로 넘어가기만 합니다.
아이디·비밀번호·포트는 관비기 컴퓨터 안에만 있고 농가 휴대폰에는 나가지 않습니다.

### 설치 (설치자가 관비기 컴퓨터에서 한 번만)

1. 이 폴더를 관비기 컴퓨터에 복사합니다.
2. [go2rtc 내려받기](https://github.com/AlexxIT/go2rtc/releases/latest) → `go2rtc_win64.zip`
   → 압축을 풀어 **`go2rtc.exe` 를 이 폴더에** 둡니다.
3. [ffmpeg 내려받기](https://www.gyan.dev/ffmpeg/builds/) → `ffmpeg.exe` 도 이 폴더에 둡니다.
   (H.265 → H.264 로 바꾸는 데 씁니다. 없으면 검은 화면이 그대로 납니다)
4. `go2rtc.yaml` 을 메모장으로 열어 **`PASSWORD` 네 군데**를 NVR 비밀번호로 바꿉니다.
5. **`CCTV_켜기.bat`** 을 더블클릭합니다. 검은 창이 뜨고 브라우저가 열리면 성공입니다.
   - 이 창은 켜 둔 채로 씁니다. 닫으면 CCTV 화면도 꺼집니다.
   - 컴퓨터를 켤 때 자동 실행하려면 바로가기를 `시작 → 실행 → shell:startup` 폴더에 넣습니다.
6. 공유기(iptime)에서 **포트포워딩 2개**를 관비기 컴퓨터 내부 IP로 추가합니다.

   | 외부 포트 | 내부 포트 | 종류 | 쓰임 |
   |---|---|---|---|
   | 1984 | 1984 | TCP | CCTV 화면 |
   | 8555 | 8555 | TCP | 영상 전송 |

7. 사이트에 `사이트-버튼.html` 의 덩어리를 CCTV 칸에 붙여 넣습니다.

### 확인
휴대폰에서 **와이파이를 끄고(LTE)** `http://eemi124.iptime.org:1984/` 를 열어
1·2·3번이 나오면 끝입니다. 첫 화면은 3~5초쯤 걸립니다. (변환기가 뜨는 시간)

### 화면에 나오는 이름

`cctv-web/index.html` 위쪽 `CAMS` 만 고치면 됩니다.

| 채널 | 화면에 나오는 이름 | 상태 |
|---|---|---|
| 1 | 1번 · 외부 | 정상 |
| 2 | 2번 · 하우스 1 | 정상 |
| 3 | 3번 · 하우스 2 | 정상 |
| 4 | 4번 · 현재 점검 중 | 영상 없음 — **목록에서 지우지 않았습니다** |

4번은 검은 화면으로 계속 돌지 않게 `[그래도 한번 보기]` 를 눌러야 시도합니다.
고치고 나면 `ok: true` 한 글자만 바꾸면 처음부터 자동으로 켜집니다.

## ② 기존 앱(EasyViewer Pro)으로 보기

`앱-설정-도우미.html` 을 사이트에 같이 올리면, 사이트의
**[새 휴대폰인가요? · 앱 설정 도우미]** 버튼이 이 화면을 엽니다.

농가가 하는 일은 이것뿐입니다.

1. **[EasyViewer Pro 열기]** — 앱이 없으면 알아서 플레이스토어로 갑니다.
2. 앱에서 `장치 → ＋ → 유선 장치 → IP/도메인` (화면에 그림처럼 순서가 적혀 있습니다)
3. 도우미 화면에서 **[복사]** 를 누르고, 앱 칸을 **길게 눌러 붙여넣기**.
   주소 → 포트 → 이름 → 아이디 → 비밀번호 다섯 줄을 차례로 반복합니다.
   지금 할 줄은 초록색으로, 끝난 줄은 `복사됨 ✓` 로 표시됩니다.
4. 앱에서 **저장**. 끝입니다. 다음부터는 앱만 열면 됩니다.

### 비밀번호는 어떻게 들어가나

도우미 화면은 **주소 뒤 `#` 에 실린 비밀번호만** 씁니다. `#` 뒤는 서버로 전송되지 않습니다.
관비기 화면(VNC)에서 이미 쓰고 계신 방식과 같습니다.

농가에게 보낼 링크:

```
https://hyeonpung-smartfarm-connect.fkausxld12.chatgpt.site/#w=실제비밀번호
```

이렇게 열면 사이트의 도우미 버튼이 그 비밀번호를 도우미 화면으로 그대로 넘겨 줍니다.
`#w=` 없이 그냥 들어오면 비밀번호 줄은 아예 안 보이고 안내 문구가 뜹니다.

### 더 줄이고 싶다면 (설치자가 한 번 준비)

같은 다후아 계열 앱인 **DMSS** 에는 **장치 카드(QR)** 기능이 있습니다.

1. 설치자 휴대폰 DMSS에 현풍 NVR을 등록 → `장치 카드 만들기` → QR 이미지가 사진첩에 저장됩니다.
2. 그 이미지를 농가 휴대폰으로 보냅니다. (문자·카톡)
3. 농가는 DMSS에서 `＋ → SN/스캔 → 오른쪽 위 사진 아이콘 → 받은 이미지 선택`

카메라로 화면을 찍는 게 아니라 **사진첩에서 고르는 것**이라 본인 휴대폰만 있으면 됩니다.
복사·붙여넣기도 필요 없습니다. 다만 앱이 EasyViewer Pro가 아니라 DMSS로 바뀝니다.

## 비밀번호 이야기 (한 번은 보셔야 합니다)

지금 `hyeonpung-cctv.m3u8` 은 사이트에서 **누구나 내려받을 수 있고**, 그 안에
`admin / admin1234` 가 그대로 들어 있습니다. 주소만 알면 남도 농장 CCTV를 볼 수 있습니다.

- ① 로 바꾸면 계정은 관비기 컴퓨터 안에만 남고 사이트에서 사라집니다.
- ② 도 비밀번호가 `#` 뒤에만 실려서 사이트 소스에는 남지 않습니다.
- 바꾸시는 김에 **NVR 비밀번호도 새로 정하시길** 권합니다. (`admin1234` 는 너무 흔합니다)

CCTV 화면 자체에도 자물쇠를 걸고 싶으면 `go2rtc.yaml` 에 넣으면 됩니다.

```yaml
api:
  listen: ":1984"
  username: hyeonpung
  password: 원하는비밀번호
```

사이트 버튼 주소만 `http://hyeonpung:원하는비밀번호@eemi124.iptime.org:1984/` 로 바꾸면
농가는 여전히 버튼 한 번입니다.

## 확인한 것 / 확인하지 못한 것

인터넷이 막힌 작업 환경에서 만들었습니다. 아래를 그대로 적습니다.

### 확인한 것 (실제로 돌려봤습니다)

- **검은 화면의 원인** — H.265 704×480 스트림을 똑같이 만들어 재현했고,
  브라우저가 `codecs not matched: video:H265` 를 뱉는 것을 확인했습니다.
- **해결 확인** — 같은 H.265 원본을 `go2rtc.yaml` 방식으로 통과시키니
  `Video: h264 (High) 704x480` 으로 나왔습니다.
- **화면 동작** — 크롬(안드로이드 390×844 크기)으로 `cctv-web/index.html` 을 열어
  카드 4개, 한글 글자, **가로 넘침 없음**, 4번 '점검 중' 표시, 영상이 실제로 그려지는 것까지 봤습니다.
- **앱 설정 도우미** — 같은 크기에서 [복사] 5줄이 순서대로 넘어가고, 실제로 클립보드에
  값이 들어가며, `#w=` 없이 열면 비밀번호 줄이 숨겨지는 것까지 확인했습니다.
- **go2rtc 설정 문법** — 실제 go2rtc 1.9.14 로 띄워서 4개 스트림이 잡히는 것을 확인했습니다.
  (`static_dir` 을 쓰면 go2rtc 기본 화면이 가려지는 것도 확인해서, 재생기 파일을
  `cctv-web/` 안에 같이 넣어 뒀습니다)

### 확인하지 못한 것

- **현풍 NVR 자체** — `eemi124.iptime.org` 의 554·37777 포트가 이 작업 환경에서 차단되어
  접속조차 못 했습니다. **1·2·3번이 지금도 나오는지 직접 재생해 보지 못했습니다.**
  (전에 하신 ffprobe 결과를 그대로 믿고 만들었습니다)
- **실제 안드로이드 휴대폰** — 휴대폰이 없어 **전혀 확인하지 못했습니다.**
  화면 크기와 동작은 데스크톱 크롬을 휴대폰 크기로 맞춰 본 것입니다.
- **EasyViewer Pro 의 현재 플레이스토어 상태·대상 API** — play.google.com 도 막혀 있어
  확인하지 못했습니다. 새 휴대폰에서 '다른 기기에서만 사용할 수 있는 앱' 이 뜨면
  ① (앱 없이 보기) 로 안내해 주세요. 그 경우엔 앱이 아예 필요 없습니다.
- **운영 사이트와 로컬 프로젝트 폴더** — 접근이 안 되어 **기존 코드를 보지 못했고,
  배포도 하지 못했습니다.** 그래서 기존 화면은 건드리지 않고, CCTV 칸에 붙일 덩어리와
  새 화면만 따로 만들었습니다. lint·production build·Sites 배포도 하지 못했습니다.

설치하시고 안 되는 게 있으면, 검은 창에 찍히는 글과 함께 알려 주세요.
